# CSC190---Team-Void-Project
Project Overview

Team Void is developing a website or application with an integrated scheduling service for a local independent barbershop. The platform will make it easier for customers to view services, book appointments, and manage their bookings while helping barbers organize their schedules and clients.

Team Members
Michael, Flynn, Abdullah, Chris, Richard, Shirzad

Project Goals
Provide a convenient appointment-booking system, Help local barber manage their schedules, Improve communication between customers and the barbershop, Create a simple and accessible user experience

This project is being developed for CSC190.
